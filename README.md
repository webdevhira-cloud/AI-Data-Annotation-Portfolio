# Customer Review Sentiment Annotation

**Portfolio owner:** Hira  
**Project type:** Independent practice project  
**Status:** Self-directed learning sample; not paid client work and not an official certification.

## Objective
Classify short customer reviews into one of four sentiment labels and explain each decision.

## Label definitions
- **Positive:** Clearly favorable opinion or experience.
- **Negative:** Clearly unfavorable opinion or experience.
- **Neutral:** Factual text without a clear positive or negative opinion.
- **Mixed:** Both positive and negative opinions are present.

## Quality-control checklist
1. Read the full review before assigning a label.
2. Apply the same label definitions consistently.
3. Ensure every review has one label and a reason.
4. Check that the reasoning is supported by the text.
5. Recheck ambiguous examples against the task instructions.

## Files
- `customer_review_annotations.csv`: 10 example reviews, labels, reasoning, and QC status.

## Important note
This is a self-created practice dataset for demonstrating learning. It does not represent work for an employer or client, and it is not an official qualification or certificate.
